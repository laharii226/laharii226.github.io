ENGINEERING SCOPE

Know what this solver does.

This first version uses elementary Euler–Bernoulli beam theory and Saint-Venant torsion for a uniform circular tube. It is an educational analytical calculator, not an FEA solver or a certified design tool.

Shear-centre location, local 3D stress fields, buckling, fatigue life, creep and photo-to-CAD reconstruction are not implemented in this version.

MECHMIND 3D Educational use only · Verify calculations independently before engineering use.
